# SOC Home Lab

## Project Type
Defensive Cybersecurity / Security Operations portfolio project.

## Overview
SOC Home Lab is a hands-on cybersecurity environment created to explore Security Operations Center concepts in a practical setting.

The project focuses on security monitoring, log analysis, investigation workflows and defensive-security thinking.

## Objective
The main objective is to understand how a SOC analyst approaches security events:

1. Collect security data
2. Observe events and logs
3. Identify suspicious activity
4. Investigate the event
5. Correlate relevant information
6. Determine whether activity is potentially malicious
7. Document findings
8. Think about an appropriate defensive response

- Blue Team methodology

## Investigation Mindset

When investigating an event, Anshuman focuses on questions such as:

- What happened?
- When did it happen?
- Which system was involved?
- Which user or process was involved?
- What evidence is available?
- Is the activity normal or suspicious?
- What indicators could help confirm the activity?
- What additional logs or events should be checked?
- What defensive action could be considered?
