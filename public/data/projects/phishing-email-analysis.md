# Phishing Email Analysis

## Project Type
Email Security / Social Engineering / Defensive Cybersecurity portfolio project.

## Overview
This project focuses on understanding how suspicious or potentially malicious emails can be identified and analyzed from a defensive-security perspective.

The project explores common phishing indicators found in email content, links and social-engineering techniques.

## Objective

The main objectives are:

- Understand how phishing attacks work
- Identify suspicious email characteristics
- Analyze suspicious links
- Recognize social-engineering indicators
- Understand common phishing techniques
- Develop a structured email-investigation workflow
- Improve defensive email-security awareness

## Phishing Indicators

Important indicators that can require investigation include:

- Suspicious sender information
- Unexpected emails
- Urgent or threatening language
- Requests for credentials
- Requests for sensitive information
- Suspicious links
- Mismatched link text and destination
- Unexpected attachments
- Poor or unusual formatting
- Impersonation of trusted organizations
- Requests to bypass normal security procedures

## Investigation Workflow

A basic phishing-analysis workflow includes:

1. Examine the sender.
2. Review the email subject.
3. Read the message carefully.
4. Identify social-engineering techniques.
5. Inspect suspicious links without opening unsafe destinations.
6. Compare displayed link information with the actual destination.
7. Examine available email metadata or headers when available.
8. Identify indicators of compromise when applicable.
9. Determine whether the message appears suspicious.
10. Document the findings.

## Social Engineering

Phishing commonly relies on psychological manipulation rather than purely technical exploitation.

Common techniques include:

- Urgency
- Fear
- Authority impersonation
- Curiosity
- Financial pressure
- Account-security warnings
- Fake rewards
- Credential requests

## SOC Relevance

Phishing analysis is highly relevant to SOC and Blue Team operations because suspicious emails can be an initial entry point for attacks.

A SOC analyst may need to investigate:

- Sender information
- URLs
- Domains
- Attachments
- Email headers
- User reports
- Related security events
- Other users who received the same message
