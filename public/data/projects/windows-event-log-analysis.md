# Windows Event Log Analysis

## Project Type
Windows Security / Event Log Analysis / SOC portfolio project.

## Overview
This project focuses on understanding Windows security events and how event logs can provide useful evidence during security investigations.

## Objective

The main objectives are:

- Understand Windows Event Logs
- Identify security-relevant events
- Analyze authentication activity
- Understand Event IDs
- Investigate suspicious behavior
- Build timelines from events
- Develop SOC investigation skills

## Important Areas

The analysis can focus on:

- User logons
- Failed authentication
- Successful authentication
- Account activity
- Privilege-related events
- Process activity
- System events
- Security events
- Event timestamps
- Usernames
- Computer names
- Event IDs

## Investigation Workflow

1. Identify the relevant event.
2. Check the timestamp.
3. Examine the Event ID.
4. Identify the user involved.
5. Identify the affected system.
6. Review the event details.
7. Search for related events.
8. Build a timeline.
9. Look for unusual patterns.
10. Document the investigation.

## SOC Relevance

Windows Event Logs can provide valuable telemetry for SOC analysts investigating:

- Suspicious authentication
- Repeated login failures
- Unexpected account activity
- Privilege changes
- Suspicious process activity
- Other abnormal system behavior
