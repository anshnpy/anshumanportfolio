# Network Traffic Analysis — Wireshark

## Project Type
Network Security / Traffic Analysis portfolio project.

## Overview
This project focuses on using Wireshark to inspect and analyze network traffic at the packet level.

The purpose is to understand how network communication can be observed, filtered and investigated from a defensive-security perspective.

## Objective

The main objectives are:

- Understand packet-level network communication
- Inspect network protocols
- Analyze source and destination information
- Identify unusual or suspicious traffic patterns
- Use filters to isolate relevant packets
- Understand how packet evidence can support security investigations

## Tool

Wireshark is used as the primary packet-analysis tool.

## Analysis Areas

The project focuses on examining:

- Source IP
- Destination IP
- Source port
- Destination port
- Protocol
- Packet timing
- Packet size
- TCP communication
- UDP communication
- DNS traffic
- HTTP/HTTPS-related traffic
- Network connection patterns

## Investigation Workflow

A typical analysis process includes:

1. Capture or open network traffic.
2. Identify the protocols present.
3. Examine communicating hosts.
4. Apply appropriate display filters.
5. Inspect individual packets.
6. Follow relevant network conversations.
7. Look for unusual communication patterns.
8. Correlate observations with the security context.
9. Document useful findings.

## Defensive Security Relevance

Network traffic analysis is useful in SOC and Blue Team environments because packet evidence can help analysts investigate:

- Suspicious connections
- Unexpected communication
- DNS activity
- Scanning behavior
- Unusual protocols
- Potential command-and-control communication
- Abnormal network behavior
