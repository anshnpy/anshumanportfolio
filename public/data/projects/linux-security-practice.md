# Linux Security Practice

## Project Type
Linux Security / System Administration / Defensive Cybersecurity portfolio project.

## Overview
This project focuses on developing practical Linux skills relevant to cybersecurity and SOC environments.

## Objective

The main objectives are:

- Understand Linux fundamentals
- Work with the command line
- Understand files and permissions
- Examine processes
- Understand users and groups
- Work with system information
- Inspect logs
- Develop Linux troubleshooting skills
- Build security-focused Linux knowledge

## Security Areas

Important areas include:

- File permissions
- Users and groups
- Processes
- Services
- System logs
- Networking commands
- File systems
- Command-line operations
- Basic system hardening concepts

## SOC Relevance

Linux knowledge is useful in SOC environments because analysts may investigate Linux servers, inspect system logs, understand running processes and examine network activity.

## Skills Demonstrated

- Linux command line
- Linux fundamentals
- File permissions
- User and group management
- Process analysis
- Log inspection
- Basic Linux security
- Troubleshooting

The project focuses on Linux fundamentals from a cybersecurity perspective, including command-line usage, permissions, users, processes, services and log inspection. These skills support security monitoring and investigation work.

## Detailed Answer

Linux Security Practice is part of Anshuman's cybersecurity foundation. The project focuses on understanding how Linux systems work and how security-relevant information can be examined from the command line.

The learning areas include file permissions, users and groups, processes, services, system logs and networking-related commands. These fundamentals are useful when investigating Linux systems in SOC and Blue Team environments.
